Support and contact.

Getting help

Write to support.NexusLedger@gmail.com. Include the state you were looking at and, if the problem is an import, the header row of your CSV — the first line only, never the orders themselves.

Common questions

My state says “rule not available”.
That state has no rule file yet. The app shows no threshold rather than a plausible one, because a default nobody checked is the worst number it could show. The states it does cover are listed inside the app under Settings → Rule sources, each with the page it was copied from and the date a person read it.
My import stopped and listed column names.
The file did not contain a column the import needs, and it refuses to guess which one you meant. Use the generic adapter and map the columns yourself, or rename the headers to one of the names it listed.
Some orders are “unassigned”.
Those orders had no destination state in the file. They are never dropped and never added to a state: their count and value sit beside every total, because a state total that quietly excluded them would tell you that you are further from a threshold than you are.
What does the subscription pay for?
Re-reading the state pages twice a year and updating the files, so the figures are still right in six months. Importing, the dashboard for the period you are in, entering your state registrations, and exporting one state stay free.
Where is my data?
On your device, in one file, and nowhere else. The app makes no network request of any kind. Settings → Your data has a button that hands you that file exactly as it is stored, and one that deletes it.

Privacy

The app collects nothing, sends nothing and has no account. It never reads a buyer’s name, email, telephone or address: the import cannot see those columns, and there is nowhere in the stored file to put them.
